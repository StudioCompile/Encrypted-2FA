Questions

Where is my data stored?

In your browser's local storage, already encrypted. Clearing browser data removes it, so export a backup from Settings.

What if I forget my password?

There is no recovery. Nothing can decrypt a vault without the password, a passkey or a backup you can still open.

Can I use it on another device?

Yes. Share the vault by link or import an exported backup. Passkeys stay on the device they were created on.

Does Vault work offline?

Once loaded, encryption and code generation all happen locally, so no connection is needed to read your codes.
